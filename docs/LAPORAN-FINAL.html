1. Deskripsi Aplikasi

JejakJamban adalah aplikasi Flutter (Android/iOS) untuk mencatat tipe Bristol dan ringkasan kesehatan pencernaan secara privat. Pengguna dapat bekerja offline; setelah masuk (login), data log disinkronkan ke backend Laravel REST API. Aplikasi ini bukan alat diagnosis medis.

Fitur utama:

  • Registrasi & login dengan data profil (alias, usia, persetujuan kesehatan).
  • Input jejak (log) buang air besar dengan tipe Bristol 1–7, catatan, waktu.
  • CRUD lengkap (Create, Read, Update, Delete) jejak via REST API dengan Bearer token Sanctum.
  • Penyimpanan lokal offline (SQLCipher) + sinkronisasi ke server saat online.
  • XP/gamifikasi untuk konsistensi pencatatan (bukan untuk leaderboard medis).

3.2 Langkah Deployment

  1. Persiapan paket production: composer install --no-dev, generate .env produksi dengan APP_ENV=production, APP_DEBUG=false, APP_KEY ter-generate, credential MySQL InfinityFree.
  2. Perbaikan .htaccess: root .htaccess di-rewrite agar hanya me-redirect ke /public/ jika path belum di dalam /public/ (mencegah rewrite-loop → HTTP 500).
  3. Upload via FTP: seluruh isi project (termasuk folder vendor/) di-upload ke htdocs/ menggunakan curl batch (6280 file, ±45 menit).
  4. Import Database: skema SQL (backend/infinityfree/schema.sql) dijalankan via script PHP di server hosting (karena DNS sql106.infinityfree.com tidak resolve dari jaringan lokal, tetapi resolve dari dalam jaringan InfinityFree). Hasil: 14 statement OK, 11 tabel terbentuk.
  5. Perbaikan middleware: menambahkan konfigurasi agar route API yang tidak terautentikasi selalu membalas JSON 401 (bukan redirect ke route login yang tidak ada).
  6. Smoke test produksi: 17 skenario pengujian API dijalankan langsung terhadap URL production — semua PASS.
