1. Pendahuluan

JejakJamban adalah aplikasi mobile untuk mencatat jejak kesehatan pencernaan — khususnya tipe Bristol — guna pemantauan pribadi. Pengguna dapat bekerja offline; setelah login, data disinkronkan ke backend REST API. Aplikasi ini bukan alat diagnosis medis.

Tugas ini meliputi deploy backend Laravel 12 ke hosting publik (InfinityFree), import database MySQL, integrasi URL produksi ke Flutter, dan pembangunan APK release.

2. Arsitektur Sistem

Flutter App (Android)
    │  HTTPS + Bearer Token
    ▼
Laravel 12 + Sanctum (InfinityFree, PHP 8.4)
    │  PDO
    ▼
MySQL (InfinityFree)

Alur request: HTTP Request → public/index.php → routes/api.php → Middleware (throttle/auth) → FormRequest Validation → Controller → Eloquent Model → MySQL → JSON Response.

3.2 Langkah Deploy

  1. Paket production. Composer install --no-dev, generate .env produksi (APP_ENV=production, APP_DEBUG=false, APP_KEY, credential MySQL).
  2. Perbaikan .htaccess. Rewrite rule asli menyebabkan infinite loop (HTTP 500). Ditambah kondisi RewriteCond agar hanya me-rewrite sekali ke folder public/.
  3. Upload via FTP. Seluruh project (termasuk vendor/) di-upload ke htdocs/ menggunakan curl batch, ±45 menit untuk 6.280 file.
  4. Import database. Skema SQL dijalankan via script PHP di server hosting. DNS sql106.infinityfree.com tidak resolve dari jaringan lokal, tapi resolve dari dalam jaringan InfinityFree. Hasil: 14 statement OK, 11 tabel terbentuk.
  5. Perbaikan middleware. Route API yang tidak terautentikasi sebelumnya membalas HTTP 500 (Route [login] not defined). Diperbaiki dengan konfigurasi redirectGuestsTo dan shouldRenderJsonWhen di bootstrap/app.php sehingga selalu membalas JSON 401.
  6. Smoke test. 17 skenario pengujian dijalankan terhadap URL produksi.

5. Integrasi Flutter

5.1 Konfigurasi URL

URL API dibaca dari environment variable saat build time:

// lib/core/config/app_config.dart
static const apiBaseUrl = String.fromEnvironment(
  'API_BASE_URL',
  defaultValue: 'http://10.0.2.2:8000/api', // emulator Android
);

Build release mewajibkan URL HTTPS — AppConfig.validate() menolak localhost/10.0.2.2/non-HTTPS di release.

5.2 Build APK

flutter build apk --release --dart-define=API_BASE_URL=https://jejakjamban.site.je/api

Hasil: APK release 66,9 MB dengan URL produksi ter-embed dan logo custom.
